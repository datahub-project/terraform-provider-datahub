# Release notes

Per-version release notes are published on
[GitHub Releases](https://github.com/datahub-project/terraform-provider-datahub/releases).

Each release body is that version's complete changelog entry, not a summary of it -- the
release notes are generated from
[`CHANGELOG.md`](https://github.com/datahub-project/terraform-provider-datahub/blob/main/CHANGELOG.md)
when the version is tagged. Read a single version on its Releases page, or the whole
history in that one file.

`CHANGELOG.md` also carries an `Unreleased` section covering work merged since the last
tag, which is the only place to see what a future version will contain.
